# Digital Lending Platform Wiki

This folder contains a Markdown wiki for an initial Go + PostgreSQL digital lending platform design.

## Files
Refer to Wiki

## Import into Wiki
1. Create or open a project Wiki.
2. Use the Wiki Git repository or clone the wiki repo.
3. Copy these Markdown files into the wiki repository.
4. Commit and push the files.
5. Set `Home.md` as the home page if your wiki workflow supports it.
6. Check Mermaid rendering in your chosen wiki engine; Mermaid support varies by platform/version.

## Import into Confluence
Markdown import support depends on your Confluence edition and installed apps. You may need a Markdown import app or paste each page into the editor and convert headings/tables/diagrams. Mermaid blocks may need a Mermaid macro/plugin.

## Important
This is a technical starting point, not a complete production implementation. Review business model, financial accounting, regulatory applicability, provider contracts, data protection and operational controls before launch.
